Azure: Kysymyksiä ja vastauksia

  1. Mikä on Azure Blob Storage?
    Tallennuspalvelu strukturoimattomalle datalle, kuten kuville, videoille ja dokumenteille.
  2. Mitä Azure Resource Group tarkoittaa?
    Säiliö, johon Azure-resurssit (kuten virtuaalikoneet ja tietokannat) ryhmitellään hallintaa varten.
  3. Mikä on Azure Virtual Network (VNet)?
    Azure-pilvessä sijaitseva virtuaaliverkko, joka mahdollistaa resurssien turvallisen tietoliikenteen.
  4. Mikä on Azure App Service?
    PaaS-palvelu verkkosovellusten ja REST API -rajapintojen nopeaan julkaisuun ja isännöintiin.
  5. Mitä tarkoitetaan Microsoft Entra ID:llä (ent. Azure AD)?
    Pilvipohjainen identiteetin- ja pääsynhallintapalvelu (IAM).
